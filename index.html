Before you start working on an issue

On GitHub, a contributor comments /context on an open issue. A GitHub Action then posts one Issue Context comment on that issue, or refreshes it, showing existing pull requests, recent discussion, and other GitHub context. This page previews that comment.

  1. Open an issue on GitHub
  2. Comment exactly /context
  3. A GitHub Action posts or refreshes the Issue Context comment
  4. Review the context, then decide how to proceed

This is informational only. It does not assign or reserve the issue. Alternative implementations remain welcome.

Design preview with illustrative example data, not live GitHub data. The production feature is the /context issue comment, not this page.
